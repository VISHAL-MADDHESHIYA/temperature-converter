# 🌡️ Advanced Temperature Converter

A modern, responsive temperature conversion web application built using HTML, CSS, and JavaScript.

The application allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin with real-time calculations, input validation, dark/light mode, copy functionality, and keyboard support.

## ✨ Features

- 🌡️ Convert between Celsius, Fahrenheit, and Kelvin
- 🔄 Real-time temperature conversion
- ⚠️ Input validation
- 🌙 Dark/Light mode
- 💾 Theme persistence using Local Storage
- 📋 Copy conversion results
- 🧹 Clear button
- ⌨️ Keyboard support
  - `Enter` → Convert
  - `Escape` → Clear
- 📊 Conversion summary
- 📱 Fully responsive design
- 🎨 Modern glassmorphism-inspired UI
- 📐 Accurate temperature formulas
- 🔗 GitHub and LinkedIn integration
